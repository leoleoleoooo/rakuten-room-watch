# rakuten-room-watch

楽天市場の商品候補を紹介する公開ページです。GitHub Pages で公開する予定です。

## 公開状況

2026-11-07 時点では未公開です。GitHub Pages は有効にしていません。
ページの生成器は別の非公開リポジトリで開発中で、生成した静的ファイルをこのリポジトリへ
書き出して公開する予定です。

## これは何か

このリポジトリの所有者が個人で運用します。楽天ウェブサービス（楽天商品検索 API）で
取得した商品情報を、表示用の項目だけに絞って静的ページとして公開します。

掲載する商品リンクには楽天アフィリエイトのリンクを含みます。リンク経由で購入があった
場合、運営者に報酬が発生します。ページには PR 表記を入れます。

## 楽天ウェブサービスのクレジット表示

楽天ウェブサービス利用規約 第13条とクレジット表示ガイドラインに従い、公開ページには
楽天ウェブサービスのバッジまたは「Supported by Rakuten Developers」の表示を、提供された
HTML を改変せずに入れます。

## このリポジトリに入れないもの

- 楽天ウェブサービスの applicationId / accessKey（鍵は公開しない）
- 楽天ウェブサービス API の生の応答（利用規約 第10条1項(9): 取得した情報を不特定多数と共有できる場所に保存しない）
- ショップの商品説明文・キャッチコピーの転記（同 第10条1項(7): 目的外の複製・改変の禁止）
